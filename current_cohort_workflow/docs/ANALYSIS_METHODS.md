# Analysis methods of the previous cohort, and how this workflow reproduces them

Catalog of every behavioural, pupil, assay and multivariate analysis shown for the previous cohort (Dec 2025), built from the lab-meeting deck and mapped to the scripts of this repository. **Methods only**: results, statistics values and figures stay outside the repository.

*New figure* = the figure id made by `python/cohort_plots.py` for any cohort. *Original script* = the previous pipeline script that makes it (run unchanged on the new `ALL_mice_longitudinal.csv`). Analyses that are not yet reproduced in Python are still covered by their original script.
